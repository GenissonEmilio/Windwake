# Windwake v0.3.0 — integração Android atualizada

Prévia Android ARM64 sobre a base integrada no remoto em 2 de novembro de 2026. Mantém o launcher upstream e as correções de saves e controles incorporadas à branch do fork.

## Incluído

- Toque no título para iniciar; seleção de saves e nome com touchscreen. Os menus iniciais apresentam temporariamente a tela do GamePad, inclusive com a configuração padrão de exibição, preservando a preferência usada durante o jogo.
- Redesenho visual dos controles agrupado em intervalos de 16 ms; entrega de input e consulta de contexto independentes desse agendamento.
- Exceção do dispositivo interno `uinput-xiaomi` do Poco para manter os controles touch acessíveis.
- Importação de saves com validação de limites e caminhos, publicação transacional da pasta completa, backup e recuperação de interrupções.
- Runtime, SDK e extrator compilados das fontes atuais. O compilador LLVM oficial é reaproveitado com checksums e identidade verificados; o antigo patch binário do runtime não é usado.
- Build Android completo separado dos artifacts pequenos de CI que contêm código placeholder e não são instaladores de jogo.

## Atualização e uso

APK Windwake para Android 13+, ARM64 e Vulkan 1.3. A identidade permanece `dev.windwake.android`; a versão Android é 0.3.0, código 4. A assinatura de distribuição deve corresponder à das versões Windwake anteriores, permitindo atualizar sem desinstalar.

O SDK atualizado pode exigir uma recompilação local do jogo. Os arquivos já preparados e os saves permanecem no aplicativo. Para primeira instalação, selecione seu próprio dump compatível: WUA ou pasta extraída permite preparar sem selecionar chaves; WUX/WUD criptografados exigem as chaves correspondentes.

Use **Settings › Quit Game** antes de importar ou exportar saves. Os padrões upstream e as opções dentro do jogo foram preservados. No Poco, os ajustes gráficos anteriormente salvos continuam sendo escolhas do usuário.

## Verificação e limites

Os contratos de saves, toque inicial, controles e dispositivos internos passaram no host. O pipeline confere o APK completo e seus componentes; a procedência identifica o commit e as versões efetivamente distribuídas.

Esta prévia não representa uma nova medição de FPS no Poco. Os números coletados em 30 de outubro pertencem ao build anterior, baseado em outro SDK, e não comprovam desempenho deste APK. A validação física do runtime atualizado deve preceder qualquer promessa de ganho de FPS ou estabilidade prolongada.

Não contém ROM, assets ou código traduzido do jogo, chaves ou saves. O shader template privado e opcional do upstream não é incluído neste build do fork; shaders não cobertos podem ser preparados durante o uso.

Consulte `SHA256SUMS.txt` e `provenance.json` nos arquivos da release para conferir o APK e sua procedência. O [guia de publicação do fork](../windwake-release.md) descreve o build e a assinatura.
